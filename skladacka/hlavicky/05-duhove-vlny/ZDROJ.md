## Úpravy proti originálu

- použito jen SVG s vlnami, logo autora a nápis Hello, World! v SVG jsou nahrazené HTML textem a navigací
- styl animace přesunut z SVG do CSS, bez prefixů -webkit-/-moz-/-ms-/-o-
- id přechodu a název keyframes přejmenované (h05-duha, h05-vlna), aby se nebily s jinými dílky
- JavaScript pro tlačítko Tweet a globální styly html/body (overflow: hidden) vynechány
- SVG vyplní šířku přes preserveAspectRatio slice
