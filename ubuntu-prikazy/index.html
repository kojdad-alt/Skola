ZÁKLADNÍ PŘÍKAZY UBUNTU – TERMINÁL

1. NAVIGACE

  • pwdkde právě jsem
  • lsobsah složky
  • ls -lpodrobný výpis (práva, vlastník, velikost)
  • ls -ai skryté soubory
  • ls -lapodrobně včetně skrytých
  • cd slozkado složky
  • cd ..o úroveň výš
  • cd ~domů (nebo jen cd)
  • cd /do kořene systému

2. SLOŽKY

  • mkdir nazev_slozky
  • mkdir -p projekty/web/podkladyvíc úrovní naráz
  • rmdir nazev_slozkysmaže prázdnou složku
  • rm -r nazev_slozkysmaže složku i s obsahem

3. SOUBORY

  • touch dokument.txtprázdný soubor
  • echo "První řádek" > soubor.txtvytvoří / přepíše
  • echo "Druhý řádek" >> soubor.txtpřipíše na konec

4. ČTENÍ SOUBORŮ

  • cat soubor.txt
  • less soubor.txtšipky, mezerník, /hledat, q = konec
  • head soubor.txtprvních 10 řádků
  • head -n 20 soubor.txt
  • tail soubor.txtposledních 10 řádků
  • tail -n 15 soubor.txt
  • tail -f /var/log/syslogsledování živě

5. NANO (EDITOR)

  • nano soubor.txt
  • Ctrl+Ouložit (potvrdit Enter)
  • Ctrl+Xkonec
  • Ctrl+Whledat
  • Ctrl+Kvyjmout řádek
  • Ctrl+Uvložit
  • Ctrl+Gnápověda

6. KOPÍROVÁNÍ, PŘESUN, MAZÁNÍ

  • cp zdroj.txt cil.txt
  • cp soubor.txt /cesta/do/slozky/
  • cp -r slozka1 nova_slozka
  • mv stary.txt novy.txtpřejmenování
  • mv soubor.txt /cesta/do/slozky/přesun
  • rm soubor.txtnevratné!

7. GREP (HLEDÁNÍ)

  • grep "slovo" soubor.txt
  • grep -i "ubuntu" soubor.txtbez ohledu na velikost písmen
  • grep -n "chyba" log.txts čísly řádků
  • grep -r "heslo" /home/uzivatel/v celé složce
  • grep -v "#" config.confřádky BEZ výrazu
  • grep -c "warning" server.logjen počet
  • grep -w "is" text.txtjen celá slova
  • ls -la | grep "test"
  • history | grep "apt"
  • ps aux | grep "firefox"

8. UŽITEČNÉ

  • Tabdoplňování
  • šipkyhistorie příkazů
  • Ctrl+Cpřerušit příkaz
  • Ctrl+Lvyčistit obrazovku (nebo clear)
  • history
  • man prikaz
  • sudo prikaz

9. UŽIVATELÉ A SKUPINY

  • sudo adduser novakinteraktivně
  • sudo useradd -m -s /bin/bash svobodaručně
  • sudo passwd svobodanastavit heslo
  • sudo passwd -d svobodasmazat heslo
  • sudo groupadd projekty
  • sudo groupdel stara_skupina
  • sudo usermod -aG projekty novakpřidat do skupiny (vždy -aG!)
  • sudo gpasswd -d petr projektyodebrat ze skupiny
  • id novak
  • groups novak
  • newgrp projektynačíst novou skupinu bez odhlášení
  • cat /etc/passwd
  • sudo cat /etc/shadow
  • cat /etc/group

10. PRÁVA

  • ls -l soubor.txt
  • ls -ld slozka
  • chmod 750 /cesta/ke/slozce
  • chmod 644 dokument.txt
  • chmod g+w projekt.txtskupině přidá zápis
  • chmod o-rwx tajne/ostatním odebere vše
  • chmod +x skript.shspustitelný pro všechny
  • sudo chown student soubor.txt
  • sudo chgrp projekty soubor.txt
  • sudo chown student:projekty soubor.txt
  • sudo chown -R anna:projekty /opt/sdilene
  • Čísla práv: r = 4, w = 2, x = 1
  • Nejčastější kombinace: 755, 644, 700, 600, 770

11. SDÍLENÁ SLOŽKA

  • sudo groupadd projekty
  • sudo usermod -aG projekty anna
  • sudo usermod -aG projekty petr
  • sudo -u anna mkdir -p /home/anna/tym_sdilene
  • sudo chgrp projekty /home/anna/tym_sdilene
  • sudo chmod 2770 /home/anna/tym_sdilene2 = setgid, nové soubory dostanou skupinu projekty
  • sudo chgrp projekty /home/anna
  • sudo chmod 710 /home/annaskupina může jen projít, ne číst
  • ls -ld /home/anna
  • ls -ld /home/anna/tym_sdilene

12. PRÁVO PSÁT DO SOUBORU PRO URČITÉ LIDI

  • sudo groupadd zapisovatelenová skupina
  • sudo usermod -aG zapisovatele annapřidat člověka do skupiny (vždy -aG!)
  • sudo usermod -aG zapisovatele petr
  • sudo chgrp zapisovatele soubor.txtsoubor dostane tu skupinu
  • sudo chmod g+w soubor.txtskupině přidá zápis
  • sudo chmod 664 soubor.txtvlastník a skupina čtou i píšou, ostatní jen čtou
  • sudo chmod 660 soubor.txttotéž, ale ostatní ani nečtou
  • ls -l soubor.txtkontrola: -rw-rw-r-- … zapisovatele
  • newgrp zapisovatelenačíst skupinu bez odhlášení (jinak odhlásit a přihlásit)
  • sudo chgrp zapisovatele /home/annasoubor v cizí domovské složce: skupina jí musí projít
  • sudo chmod 710 /home/annaskupina může jen projít, ne číst

13. PRÁVO JEN PRO JEDNOHO ČLOVĚKA (ACL)

  • sudo apt install aclkdyž ACL chybí
  • sudo setfacl -m u:anna:rw soubor.txtanna smí soubor číst i psát
  • getfacl soubor.txtkontrola
  • sudo setfacl -x u:anna soubor.txtanně právo zase vezme

14. ODEBRÁNÍ PRÁV

  • sudo chmod g-w soubor.txtskupině vezme zápis (číst může dál)
  • sudo chmod g-rwx soubor.txtskupině vezme všechno
  • sudo gpasswd -d petr zapisovateleodebrat člověka ze skupiny
  • sudo chgrp anna soubor.txtvrátit souboru vlastní skupinu
  • sudo groupdel zapisovatelesmazat skupinu
